# Contributing to seethru.media

## 👋 Welcome

We are building a trust-first news platform. This isn't just another tech project; it's an attempt to fix the incentives of modern media.

We value **clarity over cleverness**, **systems over heroes**, and **privacy by default**.

## 🚀 Getting Started

Most of the action happens in our core monorepo:

- **[seethru-media/core](https://github.com/seethru-media/core)**: The main platform (Web, Author, Admin).

To start:

1.  Fork the repository you want to work on.
2.  Clone it locally.
3.  Check the `README.md` for specific setup instructions.

## 🤝 How We Work

### 1. Transparency First
We build in public. Unless it involves security keys or private user data, discussing it in public issues/discussions is preferred over private messages.

### 2. The "No Surprises" Workflow
- **Issues first**: Please open an issue to discuss significant changes before writing code.
- **Micro-PRs**: Keep Pull Requests small and focused. One feature, one PR.
- **Conventional Commits**: We use semantic commit messages (e.g., `feat: Add login`, `fix: Typo in readme`).

### 3. Cultural Norms
- **Distrust easy answers**: Journalism is complex. If a solution seems too simple, it probably ignores a tradeoff.
- **Assume good intent**: Text communication strips nuance. Be kind.

## 🛑 The 4 Red Lines (Moderation & Content)

If you are contributing content or policy, know our absolute non-negotiables:
1.  **No CSAM** (Child Sexual Abuse Material)
2.  **No Direct Incitement to Violence**
3.  **No Doxxing** (Private info of non-public figures)
4.  **No Fraud/Spam**

Everything else is debated, not banned.
